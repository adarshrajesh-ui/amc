        <  div   class =" card " > 


          <  div   class =" card-title " > 严格占优 (Strict Dominance) </  div  > 


          <  div   class =" def-box " > 


           策略 s <  sub  > i </  sub  >  严格占优于 s <  sub  > i </  sub  > ′，若对所有对手策略组合 s <  sub  > -i </  sub  > ： <  br  > 


           u <  sub  > i </  sub  > (s <  sub  > i </  sub  > , s <  sub  > -i </  sub  > ) &gt; u <  sub  > i </  sub  > (s <  sub  > i </  sub  > ′, s <  sub  > -i </  sub  > )


          </  div  > 


          <  p  > 理性人永远不会选择被严格占优的策略 → 可 <  strong  > 迭代删除 </  strong  > （IESDS）。 </  p  >

            <  div   class =" matrix-wrap " > 


              <  table   class =" matrix " >

      <  section   class =" section "  id =" s3 " > 


        <  h2   class =" section-title " >  <  span  > 03 · NASH EQUILIBRIUM </  span  > 纳什均衡（纯策略） </  h2  > 


   



        <  div   class =" card " > 


          <  div   class =" card-title " > 定义 </  div  > 


          <  div   class =" def-box " > 


           策略组合 (s₁*, s₂*, …, sₙ*) 是纳什均衡，当且仅当对每个参与者 i： <  br  >  <  br  > 


           u <  sub  > i </  sub  > (s <  sub  > i </  sub  > *, s <  sub  > -i </  sub  > *) ≥ u <  sub  > i </  sub  > (s <  sub  > i </  sub  > , s <  sub  > -i </  sub  > *)  ∀ s <  sub  > i </  sub  >  ∈ S <  sub  > i </  sub  > 


          </  div  > 


          <  p   style =" margin-top:8px " > 即： <  strong  > 在对手策略不变的前提下，没有人有单独偏离的动机。 </  strong  >  </  p  > 


        </  div  > 


   



        <  div   class =" alert alert-gold " > 


          <  span   class =" alert-icon " > ⚡ </  span  > 


          <  span  >  <  strong  > 面试快速寻找方法 </  strong  > ：在收益矩阵中，对每列找行最大值画圈(Row player BR)，对每行找列最大值画方块(Col player BR)。同时被圈又被框的格子就是纯策略NE。 </  span  > 


        </  div  > 


   



        <  div   class =" qa-block " > 


          <  div   class =" qa-q " > 📘 例题：以下矩阵有几个纯策略纳什均衡？ </  div  > 


          <  div   class =" qa-a " > 


            <  div   class =" matrix-wrap " > 


              <  table   class =" matrix " > 


                <  tr  >  <  th  >  </  th  >  <  th  > B: Left </  th  >  <  th  > B: Right </  th  >  </  tr  > 


                <  tr  > 


                  <  td   class =" row-label " > A: Up </  td  > 


                  <  td  > (2, 1) </  td  > 


                  <  td  > (0, 0) </  td  > 


                </  tr  > 


                <  tr  > 


                  <  td   class =" row-label " > A: Down </  td  > 


                  <  td  > (0, 0) </  td  > 


                  <  td   class =" nash " > (1, 2) </  td  > 


                </  tr  > 


              </  table  > 


            </  div  > 


            <  p   style =" margin-top:10px " > • A的最优反应：B选Left → A选Up（2 > 0）；B选Right → A选Down（1 > 0） </  p  > 


            <  p  > • B的最优反应：A选Up → B选Left（1 > 0）；A选Down → B选Right（2 > 0） </  p  > 


            <  p  >  <  strong  > 纯策略NE </  strong  > ：(Up, Left) 和 (Down, Right) —— 两个均衡，是典型协调博弈。 </  p  > 


            <  p  > 注意：还存在一个 <  strong  > 混合策略NE </  strong  > （见Section 4）。 </  p  > 


          </  div  > 


        </  div  > 


      </  section  >

      <  section   class =" section "  id =" s4 " > 


        <  h2   class =" section-title " >  <  span  > 04 · MIXED STRATEGIES </  span  > 混合策略均衡 </  h2  > 


   



        <  div   class =" card " > 


          <  div   class =" card-title " > 核心原理：无差异条件 </  div  > 


          <  div   class =" def-box " > 


           在混合策略均衡中，参与者对其 <  strong  > 支撑集内的每个纯策略无差异 </  strong  > （expected payoff相等），否则会去掉差的策略。


          </  div  > 


        </  div  > 


   



        <  div   class =" qa-block " > 


          <  div   class =" qa-q " > 📘 例题（经典）：猜硬币游戏 — 求混合策略均衡 </  div  > 


          <  div   class =" qa-a " > 


            <  p  > A选正/反，B猜正/反。猜对B赢1元，猜错A赢1元（零和博弈）： </  p  > 


            <  div   class =" matrix-wrap " > 


              <  table   class =" matrix " > 


                <  tr  >  <  th  >  </  th  >  <  th  > B: 猜正 </  th  >  <  th  > B: 猜反 </  th  >  </  tr  > 


                <  tr  >  <  td   class =" row-label " > A: 正 </  td  >  <  td  > (-1, +1) </  td  >  <  td  > (+1, -1) </  td  >  </  tr  > 


                <  tr  >  <  td   class =" row-label " > A: 反 </  td  >  <  td  > (+1, -1) </  td  >  <  td  > (-1, +1) </  td  >  </  tr  > 


              </  table  > 


            </  div  > 


            <  p   style =" margin-top:10px " > 无纯策略NE（无论哪个格，某方想偏离）。 </  p  > 


            <  p  >  <  strong  > 求混合NE </  strong  > ：设 A 以概率 p 出正；B 以概率 q 猜正。 </  p  > 


            <  div   class =" math " > B的无差异条件（对猜正/猜反期望相等）：


   A出正让B猜正期望 = p·(+1) + (1-p)·(-1) = 2p - 1


   A出正让B猜反期望 = p·(-1) + (1-p)·(+1) = 1 - 2p


   令 2p-1 = 1-2p  →  p = 1/2


   



   A的无差异条件（对称）：q = 1/2 </  div  > 


            <  p  >  <  strong  > 均衡 </  strong  > ：双方各以 1/2 随机选择，期望收益均为 0。 </  p  > 


          </  div  > 


        </  div  > 


   



        <  div   class =" qa-block " > 


          <  div   class =" qa-q " > 📘 例题：非对称收益矩阵的混合策略（SIG常考类型） </  div  > 


          <  div   class =" qa-a " > 


            <  div   class =" matrix-wrap " > 


              <  table   class =" matrix " > 


                <  tr  >  <  th  >  </  th  >  <  th  > B: Left </  th  >  <  th  > B: Right </  th  >  </  tr  > 


                <  tr  >  <  td   class =" row-label " > A: Up </  td  >  <  td  > (4, 2) </  td  >  <  td  > (0, 3) </  td  >  </  tr  > 


                <  tr  >  <  td   class =" row-label " > A: Down </  td  >  <  td  > (3, 0) </  td  >  <  td  > (1, 4) </  td  >  </  tr  > 


              </  table  > 


            </  div  > 


            <  p   style =" margin-top:12px " > 无纯策略NE（请验证：每格都有人想偏离）。 </  p  > 


            <  p  >  <  strong  > 求 A 的混合策略 </  strong  > ：让 B 对 Left/Right 无差异。设 A 以概率 p 选 Up： </  p  > 


            <  div   class =" math " > B选Left的期望：  2p + 0·(1-p) = 2p


   B选Right的期望： 3p + 4·(1-p) = 4 - p


   令 2p = 4 - p  →  3p = 4  →  p = 4/3 ?? </  div  > 


            <  p  > Wait: 让  <  em  > B </  em  >  无差异需要调整  <  em  > A </  em  >  的混合。重新： </  p  > 


            <  div   class =" math " > B选Left期望 = 2p + 0·(1-p) = 2p


   B选Right期望 = 3p + 4(1-p) = 4 - p


   2p = 4 - p  →  p = 4/3  （ > 1，不合法） </  div  > 


            <  p  > 这说明矩阵中 B 实际上有 <  strong  > 占优策略 </  strong  > ：Right 弱占优（2 vs 3, 3 vs 4），等等—— </  p  > 


            <  div   class =" math " > 检查 B：Left vs Right


     A=Up:   B(Left)=2, B(Right)=3  → Right 更好


     A=Down: B(Left)=0, B(Right)=4  → Right 更好


   B 的严格占优策略：Right！ </  div  > 


            <  p  > 删除 B:Left，A 在 (Up:0, Down:1) 中选  <  strong  > Down </  strong  > 。 </  p  > 


            <  p  >  <  strong  > 唯一纯策略NE = (Down, Right)，收益 (1,4) </  strong  > 。这说明先用 IESDS 再找NE 更高效。 </  p  > 


            <  div   class =" alert alert-gold "  style =" margin-top:12px " > 


              <  span   class =" alert-icon " > ★ </  span  > 


              <  span  > 面试技巧：求混合NE前先检查有无占优策略/IESDS，能大幅简化。 </  span  > 


            </  div  > 


          </  div  > 


        </  div  > 


   



        <  div   class =" qa-block " > 


          <  div   class =" qa-q " > 📘 例题：Battle of Sexes 的三个均衡 </  div  > 


          <  div   class =" qa-a " > 


            <  p  > 夫妻二人选择看足球(F)或看歌剧(O)： </  p  > 


            <  div   class =" matrix-wrap " > 


              <  table   class =" matrix " > 


                <  tr  >  <  th  >  </  th  >  <  th  > B: 足球(F) </  th  >  <  th  > B: 歌剧(O) </  th  >  </  tr  > 


                <  tr  >  <  td   class =" row-label " > A: 足球(F) </  td  >  <  td   class =" nash " > (2, 1) </  td  >  <  td  > (0, 0) </  td  >  </  tr  > 


                <  tr  >  <  td   class =" row-label " > A: 歌剧(O) </  td  >  <  td  > (0, 0) </  td  >  <  td   class =" nash " > (1, 2) </  td  >  </  tr  > 


              </  table  > 


            </  div  > 


            <  p   style =" margin-top:10px " >  <  strong  > 纯策略NE </  strong  > ：(F,F) 和 (O,O)。 </  p  > 


            <  p  >  <  strong  > 混合策略NE </  strong  > ：设 A 以概率 p 选 F，B 以概率 q 选 F： </  p  > 


            <  div   class =" math " > 让 B 无差异：


     B选F期望 = 1·p + 0·(1-p) = p


     B选O期望 = 0·p + 2·(1-p) = 2-2p


     p = 2-2p → p = 2/3


   



   让 A 无差异：


     A选F期望 = 2q + 0(1-q) = 2q


     A选O期望 = 0·q + 1·(1-q) = 1-q


     2q = 1-q → q = 1/3


   



   混合NE：A选F概率=2/3，B选F概率=1/3


   期望收益：A = 2·(1/3) = 2/3，B = 1·(2/3) = 2/3 </  div  > 


            <  p  >  <  strong  > 总结：3个均衡 </  strong  >  — (F,F), (O,O), 和混合策略(2/3, 1/3)。 </  p  > 


          </  div  > 


        </  div  >

        <  div   class =" qa-block " > 


          <  div   class =" qa-q " > 📘 SIG 面试口头题：为什么市场上买卖价差不会被竞争压缩到零？ </  div  > 


          <  div   class =" qa-a " > 


            <  p  > 做市商之间存在囚徒困境结构：若所有做市商都把 spread 缩到极小，利润极低（类似 P,P）；若某人保持较宽 spread 其他人缩小，后者抢走订单（T vs S）。 </  p  > 


            <  p  > 但在 <  strong  > 重复博弈 </  strong  > 中（每天持续交易），触发策略（Grim Trigger）可维持合作——若有人压缩 spread，其他人立刻报复，使压缩者长期收益下降。因此现实中 spread 保持在某个有利润的水平，不会竞争到零。 </  p  >

          <  div   class =" qa-q " > 📘 求 Chicken Game 的混合策略NE </  div  > 


          <  div   class =" qa-a " > 


            <  p  > 设 A 以概率 p 选直行(D)，让 B 对 D/C 无差异： </  p  > 


            <  div   class =" math " > B选直行(D)期望 = -10p + 1·(1-p) = 1 - 11p


   B选转向(C)期望 = -1·p + 0·(1-p) = -p


   



   令 1-11p = -p  →  1 = 10p  →  p = 1/10 </  div  > 


            <  p  > 由对称性 q = 1/10。 <  strong  > 混合NE：双方各以1/10概率直行，9/10概率转向。 </  strong  >  </  p  >

        <  h2   class =" section-title " >  <  span  > 09 · DYNAMIC GAMES </  span  > 序贯博弈 · 逆向归纳 </  h2  > 


   



        <  div   class =" card " > 


          <  div   class =" card-title " > 子博弈精炼纳什均衡 (SPNE) </  div  > 


          <  div   class =" def-box " > 


           在每一个子博弈中构成NE的策略组合。消除了非可信威胁（non-credible threats）。


           求法：从博弈树末端向前逆推（Backward Induction）。


          </  div  > 


        </  div  > 


   



        <  div   class =" qa-block " > 


          <  div   class =" qa-q " > 📘 例题：进入博弈 (Entry Game) </  div  > 


          <  div   class =" qa-a " > 


            <  p  > 在位者(I) vs 进入者(E)：E 先决定进入(In)或不进(Out)，I 然后决定对抗(F)或默许(A)。 </  p  > 


            <  div   class =" math " > 博弈树：


   E选In → I选Fight: (E=-1, I=-1)


   E选In → I选Accommodate: (E=+1, I=+1)


   E选Out: (E=0, I=+3) </  div  > 


            <  p  >  <  strong  > 逆向归纳 </  strong  > ： </  p  > 


            <  div   class =" steps " > 


              <  div   class =" step " > 若 E 选了 In，I 面临 Fight(-1) vs Accommodate(+1) → I 选  <  strong  > Accommodate </  strong  >  </  div  > 


              <  div   class =" step " > E 预判 I 会 Accommodate → In 得 +1  >  Out 得 0 → E 选  <  strong  > In </  strong  >  </  div  > 


            </  div  > 


            <  p   style =" margin-top:10px " >  <  strong  > SPNE = (In, Accommodate)，收益 (1, 1) </  strong  >  </  p  > 


            <  p  > 注意：I 威胁"你进来我就打"是 <  strong  > 不可信威胁 </  strong  > ，因为真进来后 I 自己也受损，不会执行。SPNE 消除了这种威胁。 </  p  > 


          </  div  > 


        </  div  > 


   



        <  div   class =" qa-block " > 


          <  div   class =" qa-q " > 📘 例题：三层 Centipede Game（蜈蚣博弈） </  div  > 


          <  div   class =" qa-a " > 


            <  p  > A和B轮流决定：在自己回合选 Stop(S) 或 Pass(P)。每轮 Pass 使总收益增长但分配给下一个人更多。 </  p  > 


            <  div   class =" math " > 回合1(A行动): S→(2,0); P→回合2


   回合2(B行动): S→(1,3); P→回合3


   回合3(A行动): S→(4,2); P→(3,5) </  div  > 


            <  p  >  <  strong  > 逆向归纳 </  strong  > ： </  p  > 


            <  div   class =" steps " > 


              <  div   class =" step " > 回合3: A选S(4) > P(3) → A选Stop，A得4，B得2 </  div  > 


              <  div   class =" step " > 回合2: B预判回合3 A选S → B现在 S(3) vs P(B得2) → B选Stop，B得3，A得1 </  div  > 


              <  div   class =" step " > 回合1: A预判回合2 B选S → A现在 S(2) vs P(A得1) → A选Stop，A得2，B得0 </  div  > 


            </  div  > 


            <  p   style =" margin-top:10px " >  <  strong  > SPNE：A 在第一回合就 Stop </  strong  > ，收益(2,0)。 </  p  > 


            <  div   class =" alert alert-red " > 


              <  span   class =" alert-icon " > ⚠ </  span  > 


              <  span  > 实验中人们不会在第一回合就停，这挑战了理性人假设。蜈蚣博弈常被用来讨论有限理性、利他主义、以及理性的共同知识失效。 </  span  > 


            </  div  > 


          </  div  > 


        </  div  > 


   



        <  div   class =" qa-block " > 


          <  div   class =" qa-q " > 📘 例题：先动优势 vs 后动优势 </  div  > 


          <  div   class =" qa-a " > 


            <  p  >  <  strong  > Stackelberg 领导者博弈 </  strong  > （产量竞争）： </  p  > 


            <  p  > Leader 先设产量 q₁，Follower 观察后设 q₂。市场价格 P = 100 - q₁ - q₂，零成本。 </  p  > 


            <  div   class =" math " > Follower 的 BR（给定 q₁）：


     max q₂(100 - q₁ - q₂) → q₂* = (100 - q₁)/2


   



   Leader 逆向归纳代入：


     π₁ = q₁(100 - q₁ - (100-q₁)/2) = q₁(50 - q₁/2)


     d/dq₁: 50 - q₁ = 0 → q₁* = 50


     q₂* = (100-50)/2 = 25


   



   收益：π₁ = 50×25 = 1250，π₂ = 25×25 = 625 </  div  > 


            <  p  > Cournot（同时）均衡：q₁=q₂=100/3≈33.3，各得约1111。 </  p  > 


            <  p  >  <  strong  > 先动优势 </  strong  > ：Leader 收益 1250  >  Cournot 1111，先行承诺有利。 </  p  > 


          </  div  > 


        </  div  > 


      </  section  > 


   



      <!-- ══ S10 重复博弈 ══ --> 


      <  section   class =" section "  id =" s10 " > 


        <  h2   class =" section-title " >  <  span  > 10 · REPEATED GAMES </  span  > 重复博弈 · 触发策略 </  h2  > 


   



        <  div   class =" two-col " > 


          <  div   class =" card " > 


            <  div   class =" card-title " > 有限重复博弈 </  div  > 


            <  p  > 若有限次重复，逆向归纳推回：每轮均衡是单次博弈均衡。 <  strong  > 合作无法维持。 </  strong  >  </  p  > 


            <  p  > （除非有多个均衡，或者存在信誉效应） </  p  > 


          </  div  > 


          <  div   class =" card " > 


            <  div   class =" card-title " > 无限重复博弈 </  div  > 


            <  p  > 贴现因子 δ∈(0,1)，当 δ 足够大（玩家足够有耐心），合作均衡可以用触发策略支撑。 </  p  > 


          </  div  > 


        </  div  > 


   



        <  div   class =" qa-block " > 


          <  div   class =" qa-q " > 📘 例题：Grim Trigger 维持合作的条件 </  div  > 


          <  div   class =" qa-a " > 


            <  p  > 无限重复囚徒困境，收益：合作(C,C)得 R=3，背叛得 T=5，惩罚得 P=1。 </  p  > 


            <  p  >  <  strong  > Grim Trigger 策略 </  strong  > ：从合作开始，一旦有人背叛，永远背叛。 </  p  > 


            <  div   class =" math " > 合作收益（折现求和）：


     V(Cooperate) = R + δR + δ²R + ... = R/(1-δ) = 3/(1-δ)


   



   背叛收益：


     V(Deviate) = T + δP + δ²P + ... = T + δP/(1-δ) = 5 + δ·1/(1-δ)


   



   合作优于背叛的条件：


     3/(1-δ) ≥ 5 + δ/(1-δ)


     3 ≥ 5(1-δ) + δ


     3 ≥ 5 - 5δ + δ


     3 ≥ 5 - 4δ


     4δ ≥ 2


     δ ≥ 1/2 </  div  > 


            <  p  >  <  strong  > 结论 </  strong  > ：当贴现因子 δ ≥ 1/2（即玩家足够有耐心），Grim Trigger 可维持合作均衡。 </  p  > 


            <  div   class =" alert alert-blue " > 


              <  span   class =" alert-icon " > 💡 </  span  > 


              <  span  > Folk 定理：在无限重复博弈中，只要δ足够大，几乎任何帕累托改进均衡都可以被支撑。这解释了为什么长期关系中合作更容易出现。 </  span  > 


            </  div  > 


          </  div  > 


        </  div  > 


      </  section  > 


   



      <!-- ══ S11 拍卖 ══ --> 


      <  section   class =" section "  id =" s11 " > 


        <  h2   class =" section-title " >  <  span  > 11 · AUCTIONS </  span  > 拍卖理论 </  h2  > 


   



        <  div   class =" sig-badge " > ★ SIG 高频考点 — 拍卖是 SIG 文化核心 </  div  > 


   



        <  div   class =" two-col " > 


          <  div   class =" card " > 


            <  div   class =" card-title " > 一价密封拍卖 (First-Price Sealed Bid) </  div  > 


            <  p  > 最高出价者获胜，支付自己报价。 </  p  > 


            <  p  > 策略： <  strong  > 低报 </  strong  > （shading）— 报价低于真实估值以获取正剩余 </  p  > 


            <  div   class =" math " > n个对称bidder，估值v~U[0,1]：


   最优报价 b(v) = v·(n-1)/n


   



   n=2时：b(v) = v/2


   n=3时：b(v) = 2v/3 </  div  > 


          </  div  > 


          <  div   class =" card " > 


            <  div   class =" card-title " > 二价密封拍卖 (Second-Price / Vickrey) </  div  > 


            <  p  > 最高出价者获胜，支付 <  strong  > 第二高 </  strong  > 出价。 </  p  > 


            <  p  > 策略： <  strong  > 如实出价 </  strong  > （dominant strategy） </  p  > 


            <  div   class =" math " > 为什么如实出价是占优策略？


   设真实估值 v，对手最高报价 b*：


   



   情形1：v  >  b*（赢得有利）


     诚实出价v → 赢，净收益 v-b*  >  0 ✓


     低报  <   b  *   →   输，净收益   0   ✗ 


   



    情形2：v   <   b  *（赢了亏损） 


      诚实出价v   →   输，净收益   0   ✓ 


      高报   >  b* → 赢，净收益 v-b*  <   0   ✗  </  div  > 


          </  div  > 


        </  div  > 


   



        <  div   class =" card " > 


          <  div   class =" card-title " > 收益等价定理 (Revenue Equivalence Theorem) </  div  > 


          <  div   class =" def-box " > 


           在标准条件下（独立私人价值、对称、风险中性），所有标准拍卖（英式、荷式、一价、二价）给卖家带来 <  strong  > 相同期望收益 </  strong  > 。


          </  div  > 


          <  p   style =" margin-top:8px " > 直觉：虽然一价拍卖出价低但更经常赢，二价出价高但少赢，期望收益抵消。 </  p  > 


        </  div  > 


   



        <  div   class =" qa-block " > 


          <  div   class =" qa-q " > 📘 例题：两人一价密封拍卖，估值 U[0,100]，最优出价策略？ </  div  > 


          <  div   class =" qa-a " > 


            <  p  > n=2，v~U[0,100]，最优报价公式： </  p  > 


            <  div   class =" math " > b(v) = v·(n-1)/n = v·1/2 = v/2 </  div  > 


            <  p  > 即：出自己估值的一半。 </  p  > 


            <  p  >  <  strong  > 验证 </  strong  > ：对手报价 b' = v'/2，v'~U[0,100]，期望收益： </  p  > 


            <  div   class =" math " > 期望收益 = (b  >  b') × (v - b)


   最优化 FOC → b(v) = v/2 </  div  > 


            <  p  > 卖家期望收益 = E[第二高估值] = E[min(v₁,v₂)] = 100/3 ≈ 33.3 </  p  > 


            <  p  > （与二价拍卖等价，验证RET） </  p  > 


          </  div  > 


        </  div  > 


   



        <  div   class =" qa-block " > 


          <  div   class =" qa-q " > 📘 例题（SIG 真题风格）：Winner's Curse — 共同价值拍卖 </  div  > 


          <  div   class =" qa-a " > 


            <  p  >  <  strong  > 场景 </  strong  > ：石油开采权拍卖，真实价值 V 对所有人相同但未知。每个竞标者得到含噪声的信号 sᵢ = V + εᵢ，其中 εᵢ~N(0,σ²) 独立。 </  p  > 


            <  p  >  <  strong  > Winner's Curse </  strong  > ：赢得拍卖意味着你的信号是 <  strong  > 最高的 </  strong  > ，而最高信号往往高估了真实价值。 </  p  > 


            <  div   class =" math " > E[V | 赢得拍卖] = E[V | sᵢ = max(s₁,...,sₙ)]


                            <   E  [V   |   sᵢ] 


   



    理性出价：应对信号做下调，b(sᵢ)   <   E  [V   |   sᵢ]  </  div  > 


            <  p  >  <  strong  > 金融中的 Winner's Curse </  strong  > ： </  p  > 


            <  ul   class =" tree " > 


              <  li  > IPO 认购：机构对热门 IPO 的分配往往意味着机构不想要该股票（逆向选择） </  li  > 


              <  li  > 并购溢价：收购成功往往意味着你出价最高，可能高估了协同效应 </  li  > 


              <  li  > 做市商：成交说明对方有信息优势（Adverse Selection） </  li  > 


            </  ul  > 


          </  div  > 


        </  div  >
