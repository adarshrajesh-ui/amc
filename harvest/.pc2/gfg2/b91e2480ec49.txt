 AQR Capital Interview Experience for Software Engineer Full Time

 Last Updated : 23 Jul, 2025 

 It was an off-campus opportunity. There were 2 rounds in total. 

 Round-1 

 The round lasted for 30 minutes. It was in online mode. 

 The interviewer told me to Introduce myself. 
 Then the interviewer asked me to differentiate between String builder vs String. 
 He told me to explain about Smart Pointer . Then he asked me to briefly explain about Directives on Angular. 
 Suggestion - Be confident about your answers. 

 Round-2 

 The round lasted for 60 minutes. It was in online mode. 

 In this round, the interviewer gave me OUTPUT Questions which means he gave me questions (piece of code) for which I need to find the output. 

 He also asked me some SQL queries. 

 Coding Question : 

 Reverse the words in a given string 
 Given a list of strings: {area, acre, bat, ball, Amsterdam, am, AmsterdaM}. Find the string that contains a , A,m,M in it. 
 Given a list of numbers 1-50. Find these numbers i.e. Expected output - 2,12,22,32,42. 
 Tip - Practise Questions from Geeks For Geeks. Always try to solve the coding questions using different approaches. Also, give the optimized solution for coding questions. 

 Result 

 I was not selected in this round.
