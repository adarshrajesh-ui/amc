            <a href="/blog/entry/145050">            <p>De Shaw Online Assessment (OA) IIT Bhubaneswar (2025) (for SDE Intern)</p>
</a>
    </div>

        <div class="info" style="position:relative;">
                By&nbsp;<a href="/profile/AdityaDSingh" title="Specialist AdityaDSingh" class="rated-user user-cyan">AdityaDSingh</a>,

    <div class="content">
        <div class="ttypography"><p>This is a write-up of the DE Shaw Online Assessment for the SDE Intern 2025 role. The test consisted of 3 DSA problems with the following structure:</p><h2>Format</h2><p>3 programming questions</p><p>Separate timers for each question:</p><p>Q1: 20 minutes Q2: 30 minutes Q3: 30 minutes</p> <ul>   <li>Questions had to be attempted in order.</li>   <li>No ability to return to a previous question.</li>   <li>Time left on a previous question could not be transferred to the next.</li> </ul><h3>Problem 1: Divisible Substrings (20 mins)</h3><p>Given a string s of lowercase English letters (length ≤ 1000), map each character c to a value using:</p> <pre><code>val(c) = (c - 'a' + 1) / 3 + 1
</code></pre><p>For example:</p><p>'a', 'b' → 1 'c', 'd', 'e' → 2 ... 'x', 'y', 'z' → 9</p><p>Count the number of substrings such that the sum of character values in the substring is divisible by the length of that substring.</p><p>A brute-force O(n²) approach, utilizing a nested loop, is effective.</p><h3>Problem 2: Airport Scanner Simulation (30 mins)</h3><p>Given two arrays:</p><p>time[i]: time when the i-th person wants to access the scanner (sorted) direction[i]: 0 if arrival, 1 if departure</p><p>Only one person can use the scanner at a time. At any given time, the priority rules are:</p> <ul>   <li>If the scanner was used in the previous second, the same direction gets preference.</li>   <li>If unused in the previous second, departure (1) gets preference.</li> </ul><p>Determine, for each person (in input order), the exact time they pass through the scanner.</p><p>This is a simulation problem. Maintain two queues (one for arrivals, one for departures), both with (index, time) pairs. Process second-by-second, applying the direction rules carefully. Track the scanner's usage state at each second.</p><h3>Problem 3: Nearest Sensor in Row or Column (30 mins)</h3><p>Given n sensors (n ≤ 10⁵), each with:</p><p>A unique string identifier</p><p>An (x, y) coordinate with 0 ≤ x, y ≤ 10⁸</p><p>You are given q queries, each being a string ID of a sensor. For each query, report the nearest sensor in the same row (same y) or the same column (same x). If there are multiple such sensors at the same distance, choose the one with the lexicographically smallest ID. If there are no such sensors, return &quot;NONE&quot;.</p><p>The approach was as follows:</p> <ul>   <li>Group all sensors by their x-coordinate and y-coordinate.</li>   <li>For each group (i.e., each row or column), sort the sensors by their other coordinate.</li>   <li>Store these sorted vectors of (coordinate, ID) pairs.</li>   <li>For each sensor, check its position in its row and column group, and examine only the immediate neighbors (i.e., previous and next in the sorted list).</li>   <li>Compare the distances and pick the closest sensor. In case of a tie, choose the one with the smaller ID.</li> </ul><p>Summary Q1: Straightforward brute-force or prefix sum-based substring counting. Q2: Simulation-heavy with direction-based rules and careful time tracking. Q3: Coordinate grouping with adjacent comparisons in sorted row/column lists.</p><p>The problems increased in complexity, testing implementation ability, data structure usage, and simulation accuracy under time constraints.</p></div>

        function updateTopicVote(topicId, voteDirection, processed) {
            let ratingElement = $(".topic-rating-" + topicId);
            let newRating = parseInt(ratingElement.attr("data-rawRating"));
            if (!processed) newRating += voteDirection;
            if (newRating > 0) {
                ratingElement.text("+" + newRating.toString());
                ratingElement.css("color", "green");
            } else {
                ratingElement.text(newRating.toString());
                ratingElement.css("color", "gray");
            }
            let voteUpImg = $(".topic-vote-up-" + topicId + " img");
            voteUpImg.attr("src", "//codeforces.com/codeforces.org/s/36785/"
                + (voteDirection === 1 ? "images/actions/voteup-voted.png" : "images/actions/voteup-gray.png"));
            voteUpImg.attr("title", voteDirection === 1 ? "Cancel vote" : "Vote: I like it");
            let voteDownImg = $(".topic-vote-down-" + topicId + " img");
            voteDownImg.attr("src", "//codeforces.com/codeforces.org/s/36785/"
                + (voteDirection === -1 ? "images/actions/votedown-voted.png" : "images/actions/votedown-gray.png"));
            voteDownImg.attr("title", voteDirection === -1 ? "Cancel vote" : "Vote: I do not like it");
        }

                }
