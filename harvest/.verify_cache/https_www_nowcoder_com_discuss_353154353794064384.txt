tw-relative" data-v-341be250><!----> <!----> <div class="content-post-title"><h1>前端岗位春招总结，回馈社区</h1> <!----></div> <!----> <!----> <!----> <div class="nc-post-content"><h1>  前端岗位春招总结，回馈社区 </h1> <p>  应一位朋友的要求，把自己春招经历及相关的写写，之前有发过面试经验帖子，朋友吐槽全是题目，而且很分散，然后又发的早没有加上我后来的经历，遂总结性的写写 </p> <h2>  准备 </h2> <p>  其实我接触牛客网蛮早的，我在去年这个时候就潜水在讨论区，当时看到18的找实习，17的找正式工作，感触颇深，遂开始早早的做准备 </p> <p>  准备的有以下几个方面： </p> <ul>  <li>   基础   <ul>    <li>     牛客网上刷html/css,javascript两个专题        <li>     收集当时讨论区的各种面经，一条一条的看，不会的就去学        <li>     阅读经典书籍：&lt;你不知道的javascript&gt;,&lt;深入浅出nodejs&gt;等        <li>     公众号文章：前端大全，前端早读课       </ul>    <li>   项目   <ul>    <li>     提前实习：10月进入一家小有名气的互联网公司实习        <li>     学校里的项目尽量用全新的技术栈去实现       </ul>   </ul> <p>  受学长简历的影响，我从大二暑假就开始思考，简历上应该要写什么项目上去合适，应该写到什么程度，写上去的东西里面有自己不熟悉的吗，每个东西都去深入了解过了吗，所以后来春招没有遭遇过简历挂 </p> <h2>  学习 </h2> <p>  其实我在17年之前都是在做java web相关的，web前端这一块的开发甚至还停留在jQuery+bootstrap，甚至还在前端js里面最原始的手段拼接过html字符串，也是在17年上半年在一个小公司实习的时候，逐渐转型做现代前端开发 </p> <p>  下面我简单的写下我自己认为现在前端所应该具备的知识，也是我个人的相关学习经历，仅仅是我个人之见，如有异议还请见谅<br> (因为我没有做过移动端的开发，所以也没怎么接触过移动端的知识，万分抱歉) </p> <p>  我的前端技术栈是React技术栈，React的学习主要是以下几个方面： </p> <ul>  <li>   入门：陈屹的&lt;深入React技术栈&gt;    <li>   React深入：项目问题的解决及社区各种文章    <li>   Redux入门：dva.js    <li>   Redux深入：Redux官方文档   </ul> <p>  面试中问到React相关的，大的方面大概有以下几个： </p> <ul>  <li>   React生命周期及其相关钩子函数    <li>   React v16新特性    <li>   React diff fiber    <li>   React与其他库的结合(实际场景实际分析)    <li>   React性能优化    <li>   React ssr    <li>   Redux设计原则与flux架构    <li>   React与Redux源码相关    <li>   React与其他框架的对比   </ul> <p>  也用过vue，但是项目里深入的不够，面试的时候就说了vue不是很熟，所以遇到的问题不是很深入，学习的话基本上就是官方文档，相关的问题如下： </p> <ul>  <li>   vue双向绑定原理与源码    <li>   vuex和redux的异同    <li>   vue diff和react diff异同    <li>   vue生命周期及其相关钩子函数   </ul> <p>  从react和vue这两个现在主流的框架的相关问题可以看出，在面试时关于框架的问题一般都会涉及到底层实现和生命周期，状态管理等，所以一定要多看官方文档，千万千万不要出现只是用过就写在了简历上的情况，那样会彻底凉掉的 </p> <p>  原生js的学习的话，主要是： </p> <ul>  <li>   多看书！&lt;你不知道的javascript&gt;&lt;javascript高级程序设计&gt; &lt;- 必看    <li>   es6: 阮一峰老师的开源书籍:<a href="https://gw-c.nowcoder.com/api/sparta/jump/link?link=http%3A%2F%2Fes6.ruanyifeng.com%2F" target="_blank">ECMAScript 6 入门</a> (现在里面的内容还有es6后面的内容)    <li>   深入理解js异步   <ul>    <li>     Promise机制        <li>     async await        <li>     事件循环        <li>     宏任务微任务        <li>     ..       </ul>   </ul> <p>  html/css的学习，主要就是w3c的教程配合刷题，这个方面需要多花时间去记，如果有时间，可以自己去实现一些精美的效果那更好 </p> <p>  接下来就是nodejs即后端，我身边很多前端er觉得nodejs是后端的，不需要学习也不需要接触，殊不知，现代前端其实就是JS工程师，所有能用JS做到的事都应该去尝试与学习，更别说现在前端这个大环境，JS全栈是有很大的优势的 </p> <p>  学习的话，主要以下几个方面： </p> <ul>  <li>   朴灵老师的&lt;深入浅出nodejs&gt; &lt;- 必看   <ul>    <li>     特点与I/O密集        <li>     v8内存管理     <ul>      <li>       新生代老生代算法            <li>       内存限制           </ul>        <li>     Libuv        <li>     进程管理: cluster和pm2       </ul>    <li>   框架: express和koa    <li>   框架深入: koa源码，很值得学习    <li>   数据库：MongoDB/Redis的应用及简单深入   </ul> <p>  既然说到了后端，那不可避免就要说到架构相关: </p> <ul>  <li>   Nginx配置与特点    <li>   Rest架构与新的Graphql    <li>   应用部署Docker   </ul> <p>  可视化这一块，其实水很水，面试的时候只要不说是专门搞可视化的话，基本上也就停留在canvas和svg以及库的使用上，写写与js相关的东西 </p> <ul>  <li>   Canvas和SVG    <li>   D3.js    <li>   Echarts与G2,G6    <li>   Zrender    <li>   webgl   </ul> <p>  最后，最重要的我一直没有说，那就是计算机的基础，尤其&lt;计算机网络&gt;,&lt;操作系统&gt;,&lt;数据结构与算法&gt;这三大部分，相当重要！相当重要！相当重要！ </p> <h2>  阿里 </h2> <p>  阿里是我第一家投递的公司，也是等待最长的<br> 时间流程为： </p> <ul>  <li>   2.28投递简历    <li>   3.2完善完简历，学长帮忙进行了内推，进入内推流程    <li>   3.5一面    <li>   3.7二面    <li>   3.12三面总见面    <li>   3.17交叉面    <li>   3.21hr面    <li>   4.15晚收到意向书    <li>   4.19收到邮件offer   </ul> <p>  具体的面试问题请参考我之前发过的: <a href="https://gw-c.nowcoder.com/api/sparta/jump/link?link=https%3A%2F%2Fwww.nowcoder.com%2Fdiscuss%2F68211" target="_blank">阿里19届前端实习生5面经历已收到offer</a>  </p> <p>  总的来说，面试阿里的时候前三面发挥比较好，交叉面发挥一般导致评级没有上A+,hr面中规中矩 </p> <h2>  腾讯 </h2> <p>  仔细想想，腾讯应该挂了我3次吧，说起来比较好笑啊 </p> <ul>  <li>   提前批第一个部门，面的挺好的，问我以后想做交互这一块吗，我说不想，于是就没有然后了    <li>   提前批第二个部门，被某个不知名部门捞了起来，做了一个笔试，矩形拖动题和大数相加，做完就没有后续了，猜测应该是拖动题没有考虑ie的兼容情况    <li>   正式批，初试表现很好，聊了一个半小时，复试...玄学   </ul> <p>  提前批的面试情况请参考：- <a href="https://gw-c.nowcoder.com/api/sparta/jump/link?link=https%3A%2F%2Fwww.nowcoder.com%2Fdiscuss%2F68710" target="_blank">腾讯19届前端实习生面试一面二面</a>  </p> <h3>  正式批 </h3> <h4>  一面 </h4> <p>  时间是4.11 </p>   <li>     用过的ES6特性        <li>     闭包        <li>     原型链        <li>     sigmajs如何和react结合        <li>     Redux设计原则        <li>     Graphql        <li>     函数式编程: 应用,思想       </ul>    <li>   node   <ul>    <li>     说说你对node的了解        <li>     内存限制(node默认最大内存多大)        <li>     v8垃圾回收机制        <li>     新生代老生代回收算法        <li>     内存管理        <li>     Hapi和koa的对比       </ul>    <li>   network     </ul>    <li>   DS &amp;&amp; Algorithms   <ul>    <li>     快速排序: 描述，复杂度        <li>     二叉树的查找        <li>     B树,B+树,红黑树       </ul>   </ul> <h4>  二面 </h4> <p>
